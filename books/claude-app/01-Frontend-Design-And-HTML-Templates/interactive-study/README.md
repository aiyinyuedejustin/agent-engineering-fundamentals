# 留白 · 可交互界面研究

> 独立研究示例，非 Claude 官方产品。

这是一个原创、中文、离线可用的桌面 AI 界面设计学习示例。它把静态证据中的部分色彩数值，放到独立编写的语义变量、组件与交互中，便于观察“同一套设计原则如何进入实现”。它不是 Claude 客户端，不提供模型服务，也不是官方源码或像素级复刻。

## 运行

直接用现代浏览器打开 `demo/index.html`。不需要安装依赖、启动服务器、登录、联网、API key 或编译。

若希望通过本地 HTTP 查看，在仓库根目录执行：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/demo/`。服务仅用于本地静态文件查看，不是应用后端。

兼容目标为支持 `dialog`、CSS 自定义属性、`inert`、`matchMedia` 与 `dvh` 的现代 Chromium、Firefox、Safari。页面不加载外部字体、图标包、CDN、分析脚本或其他远程资源。

## 可以操作什么

- 浅色 / 深色主题：切换后更新整页语义映射与色板值。仅主题选择尝试保存在本机 `localStorage` 中；存储不可用时仍可使用。
- 导航：对话与阅读、组件图谱、语义变量；窄屏导航使用遮罩、背景 `inert`、焦点循环和 Esc 退出。
- 本地模拟对话：输入并发送、停止生成、模拟失败、保留输入后重试。所有回复均为预置文字；任何输入都不会被发送到网络。
- 研究注释：结构 / 色板 / 状态三个键盘可导航标签页；切换组件边界；检查当前状态。
- 内容预览与说明窗口：浏览器原生模态窗口，支持 Esc、背景点击关闭和触发按钮焦点恢复。
- 输入检查：验证长度后显示具体错误，并保持原输入。
- 复制示例文字：剪贴板不可用时选中文字，让用户手动复制。
- 试样密度：紧凑 / 舒适切换一组原创几何值，仅作用于组件图谱中的框内试样。
- 消息阅读：14 / 16 / 18 px 独立选择，改变对话和试样正文，控件保持自己的字号。
- Quick Entry：页面内的横向速记，选择本地去向、输入、暂存最近一条记录；Esc 收起并保留草稿。
- 对话与速记只存在于页面内存中。重置或“新的观察”恢复初始对话并清空速记；阅读和密度选择留到刷新为止。刷新恢复所有默认值，主题仍按原有存储规则处理。

## 证据与原创提案的边界

### 观察到的事实

本研究选用的部分颜色字面值，可在所检 Claude Desktop Linux `2.37337.1` 安装包的静态 CDS CSS 声明中找到：

- 浅色 surface 0 / 1 / 2：`#f9f9f7` / `#fcfcfb` / `#ffffff`
- 深色 surface 0 / 1 / 2：`#0b0b0b` / `#151515` / `#1a1a19`
- 浅色主要 / 次要文字：`#0b0b0b` / `#52514e`
- 深色主要 / 次要文字：`#f0efec` / `#c3c2b7`
- Clay：`#d97757`；蓝色交互色角色中的一个值：`#2a78d6`

这些只是声明存在的证据。它们不能证明实际 DOM 匹配、加载顺序、级联后的 computed style、运行时覆盖、用户默认设置或功能可用性。不能把示例截图当作官方客户端截图。

`evidence.js` 保存源文件名、SHA-256、选择器、块编号与字节范围，供与完整研究文档交叉检查。范围从 0 开始，UTF-8 字节，末端不包含在内。页面只分发事实摘要，不分发提取的样式表或应用源码。

### 本研究独立决定的部分

- 所有 `--study-*` 语义名称与其组件用途
- 页面品牌“留白”、两笔几何标记、布局、内容、图标、组件类名、DOM、状态机
- 通用 .study-button 最小高度 40 px；新密度试样局部切换 40 / 48 px。分段按钮、主题切换和注释链接另有尺寸。导航和阅读区宽度、响应式断点、消息样式也为原创
- 系统无衬线 / 系统衬线的字体替代与中文阅读策略
- 辅助文字加深、输入边界加强、错误与成功配色
- 操作使用中性色，Clay 只做有限提示；焦点独立使用蓝色
- 动效与等待时长；减少动态效果偏好下取消逐字呈现

因此，即使某个数值来自静态观察，把它用于本示例某个组件的决定仍是“原创映射”。色板明确区分“观察值 · 原创映射”与“研究新增值”。

## 第二阶段：两条轴与一条短输入

### 密度与阅读独立

入口为“组件图谱”顶部，也可从对话标题下的“调整阅读与试样密度”进入。密度只改变 `#density-example`；消息阅读大小通过根元素的 `data-message-size` 传给对话的用户消息、助手正文和试样段落。不会把整个页面按比例缩放。

| 原创参数 | 紧凑 | 舒适 |
|---|---:|---:|
| 控件最小高度 | 40 px | 48 px |
| 图标 | 16 px | 20 px |
| 试样内边距 | 12 px | 20 px |
| 内部间距 | 8 px | 12 px |
| 控件与试样圆角 | 8 px | 12 px |
| 试样操作文字 | 13 px | 14 px |

消息大小是另一条轴：小 / 中 / 大为 14 / 16 / 18 px，默认中，行高系数为 1.9。助手初始示例的开篇段落在该尺寸上再加 2 px；流式正文与普通正文使用所选尺寸。消息操作仍使用自己的 11 px，内容预览卡恢复操作字体。输入区与 Quick Entry 不消费消息字号。

这组 40 / 48 px 值是原创教学选择。所检 CDS 默认 / comfortable 控件声明换算为 24 / 32 px；本例没有照搬该几何，也没有恢复其 rem-scale、全部组件密度或运行时偏好。证据关联见 `data/design-token-summary.json` 的 density 与 `data/design-component-rules.json` 的 message_text_preferences；关联说明研究起点，不证明实现相同。

选择只存在本页 DOM 内存，不新增 localStorage 键。切换主题、章节、重置对话不会改变这两项；刷新恢复紧凑和中号。CSS 变量和界面数值在新增静态测试中互相核对，但真实计算样式、命中区域、字体与窄屏换行仍须浏览器检查。

### Quick Entry 与完整 Composer 分开

完整 Composer 保留“编辑区在上、工具行在下”的结构和 3,000 字符限制。Quick Entry 是独立表单 `.study-quick-entry`，把本页去向 select、短文本 textarea 与暂存按钮放在同一水平轴；默认收起，不与完整 Composer 共用输入、组合状态或计时器。

- 原创外框最小高度 48 px、圆角 12 px、输入 16 px / 1.5；实际高度还受内容、padding 和边框影响，不宣称恒为 48 px
- 输入最多 300 个 UTF-16 code units，和原生 maxlength 的计数方式一致；程序化超长输入也拒绝暂存，并保留原文
- 普通 Enter 暂存；Shift / Alt / Ctrl / Meta + Enter 不触发暂存，具体编辑行为由浏览器决定。Shift + Enter 的原生换行仍需真实浏览器确认
- compositionstart / compositionend、isComposing 和 keyCode 229 保护组合输入；组合期间 Esc 不收起
- Esc 或“收起速记”保留草稿、去向并恢复打开按钮焦点；重新打开聚焦输入
- 只显示最近一条已提交记录。改变去向不会改写旧记录；再次暂存替换最近记录。“清除这条记录”不删新草稿
- 用户输入只写入 textContent，不作为 HTML 解析；不调用模型或业务 API，不保存到磁盘
- “新的观察”与重置对话清空速记；页面关闭或刷新也会丢失草稿与记录

C11 / C12 说明被研究产品有独立的 Quick Entry 本地表面与静态处理分支。本例是页面内原创试样，尺寸、关闭方式与捕获含义均独立决定；没有系统窗口、全局快捷键、外部点击关闭、原生窗口调高、拖动区域、当前应用上下文或真实会话提交。不要把它称为 Claude Quick Entry 的恢复实现。

### 显式动作后的焦点

Stop、右侧“模拟生成 / 模拟错误”、重试会禁用或隐藏原触发控件。用户主动执行这些动作后，示例把焦点送到完整 Composer；窄屏注释抽屉会先关闭并解除 inert。正常异步完成或失败不使用这条焦点路径，不抢走另一个输入的焦点。

若停止发生在第一段模拟内容之前，回复明确写“已停止，尚未生成内容。”，不为等待占位文案提供复制按钮；已有部分正文时则保留正文和复制动作。

这组修复来自对基线公开预览的浏览器观察。新增回归在模拟 DOM 中检查了事件和焦点调用；它们不能替代第二阶段在真实浏览器中的重新验证。

### 第二阶段验证范围

`04-Extracted-Core-Code-And-Scripts/tests/phase2-components/` 新增独立的 32 项模拟 DOM 检查与 10 项静态检查，复用原有固定版本 jsdom；原来的 `04-Extracted-Core-Code-And-Scripts/tests/demo-state/` 文件未改。新增检查覆盖两轴独立、草稿保留、Quick Entry 的输入/提交/组合/关闭/清除/超长/文本安全，以及显式动作和异步完成的焦点区别。

执行会生成独立报告，不覆盖已发布的基线参考数据。仍需真实浏览器核验新布局、font-size 级联、缩放、实际中文输入法、真实键盘默认行为、屏幕阅读器、原生焦点和 file:// 加载。公开预览正常加载静态资源不等于“网络请求为零”；本实现的限定是没有外部字体/CDN，以及输入不触发模型或业务 API。

## 可访问性实现意图

- 原生按钮、表单、标签、`disabled`、`aria-invalid` 与可见焦点
- 中文输入法组合期间不响应 Enter 发送；Shift + Enter 换行
- 标签页左右箭头 / Home / End 导航
- 模态窗口使用原生 `dialog.showModal()`，关闭时恢复焦点
- 窄屏导航提供背景隔离、焦点循环、Esc 与点击遮罩关闭
- 流式内容不逐字打断屏幕阅读器，仅播报状态完成 / 中断
- 停止与重置取消计时器并使过期回调失效
- 错误不仅通过颜色表达，包含标题、说明、图标和重试操作
- 表单边界独立于装饰分隔线；高对比模式保留边框与开关选中提示

这些是实现设计，不等于已经完成完整 WCAG 合规审计。请以仓库最终验证报告为准，尤其关注实际字体、缩放、移动端、输入法与辅助技术差异。

## 手动检查路径

1. 使用 `file://` 直接打开；确认没有网络资源、错误或缺失样式。
2. 切换浅色 / 深色，查看结构 / 色板 / 状态与组件图谱；检查文字和控件边界。
3. 输入中文，组合候选时按 Enter；应只确认候选，不发送。再按 Enter 应发送。
4. 生成中停止、连续点击、切换章节、重置；等待后不得出现陈旧回复。
5. 启用“下一次发送模拟失败”；失败后应保留输入，重试不得重复添加用户消息。
6. 关闭 / 禁用存储与剪贴板权限，确认主题仍可切换，复制提供手动回退。
7. 用 Tab 打开并关闭模态窗口；确认焦点回到触发按钮。
8. 窄屏展开导航，循环 Tab、Shift + Tab、按 Esc；背景应不可聚焦。
9. 启用系统“减少动态效果”；模拟回复应一次呈现，控件无过渡动效。
10. 在 320、390、768、1440 px 宽度与放大字体下检查无横向溢出；使用高对比模式检查开关与边界。
11. 在组件图谱遍历密度 × 阅读的六种组合；确认框内间距与正文独立变化，复制按钮、工具栏和完整输入区不随阅读字号放大。
12. 打开速记，切换去向，输入、Esc 收起、重新打开；检查草稿和焦点。暂存两条不同记录，再清除；检查只保留最近一条且不影响新草稿。
13. 在第一段生成前停止，检查占位文案与复制按钮；在生成中停止，检查部分内容。用键盘触发模拟生成、模拟错误、重试，检查焦点回到输入，异步完成不抢焦点。
