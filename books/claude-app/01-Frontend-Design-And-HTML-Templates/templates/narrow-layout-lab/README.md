# 固定模板的窄容器布局检查

直接用普通浏览器打开 `fixture.html`，或[在线打开固定版本](https://htmlpreview.github.io/?https://github.com/aiyinyuedejustin/agent-engineering-fundamentals/blob/bc1674f59edf3e41aaa2869a695b077e496a75d5/books/claude-app/01-Frontend-Design-And-HTML-Templates/templates/narrow-layout-lab/fixture.html)。六份公开原创模板以内嵌 UTF-8 源字节载入 `iframe.srcdoc`；不加载外部资源，也不读取运行时相邻文件。没有 URL、文件上传或任意源代码装载入口。

- 选择六个模板，切换 **375 / 768 / 1024 CSS px** 内容框宽度，固定高度 **900 CSS px**。
- 宽度按钮不会重载模板；切换模板或点“重新装载初始模板”会丢失临时输入。
- 画布过宽时横向滚动，不使用缩放或 transform。页面显示选中宽度、父页面测得的 iframe 内容框尺寸、源文件名和完整 SHA-256。
- 这是 CSS 视口断点/排版检查工具。不是 DevTools、设备仿真、浏览器设置修改，不能代表 Android/iOS、触摸、真实设备、200% 缩放、IME 或辅助技术验收。
- 实测尺寸来自 iframe 元素本身；隔离源下不读取子页面 innerWidth。子页面滚动条可能影响内部可用排版宽度。`load` 事件和源码摘要通过不等于视觉、脚本行为或 CSP 执行通过。

## 安全与存储合同

外层固定使用 `sandbox="allow-scripts"`，**不添加 `allow-same-origin`**。模板脚本可以运行，但 localStorage 被拒绝，六页走各自已有的异常回退。此次只验收布局与该条件下的本地交互；持久化、剪贴板、完整独立页面行为不在合同内。srcdoc与承载页面的base还会影响URL解析；独立页面导航须另测。外层未提供 `allow-forms`，因此表单提交类交互不能作为通过依据，也不应把这个隔离限制直接记成原模板回归。不要输入私密数据。没有为存储兼容而去掉或放宽沙盒。

外层 CSP 只允许六份固定模板与一段控制脚本的 SHA-256、内联样式和 `about:` 子框架；禁止网络资源、外部脚本、对象、基址和表单导航提交。它是额外约束，不是把未知代码变成可信代码的方法。必须单独以真实浏览器确认实际执行，不把下面的静态检查当作浏览器拦截证据。

模板 03 的原有编辑器仍然接受其原本的静态 HTML/CSS 练习输入，经原净化器进入原 `sandbox=""` 内层 iframe。其禁止脚本/网络的 CSP、净化器和替换文档流程都没有改动。此工具没有新增任意源码、URL、上传或消息桥入口。

## 来源、版本与可重建性

唯一维护源仍是仓库中的：

`../01-component-gallery.html` 至 `../06-floating-launcher-template.html`

本目录是 `templates/narrow-layout-lab/`，六份 HTML 位于上一级 `templates/`。构建器以该前端章节为根解析固定的 `templates` 来源目录；移动整个章节或整包复制时保留这个相对结构。

`source-lock.json` 精确列出六个固定文件名、长度、SHA-256，以及集合内容版本。集合摘要是 templates 数组按 `ensure_ascii=false`、排序键、紧凑 JSON 编码后的 UTF-8 SHA-256。当前版本：

`be68a58fb3ae9e3ec2a0c6b27b4c1351220e23e2fc1273e283aa2182031dc945`

生成文件只保存可再生的 Base64 字节载荷，不维护第二套手工 HTML 源码。构建器先逐项验证固定源；任何漂移立即失败，没有自动刷新锁或自动接受新源的选项。若正式模板更新，先审阅变化，明确更新内容锁，再生成新的输出文件。本页不会偷偷读取新版本。

浏览器有 WebCrypto 时，解码后再次核对所选源 SHA-256；没有 WebCrypto 时明确标注“仅构建时校验”，不伪报运行时摘要通过。选择异步切换采用代次检查，旧摘要任务不会覆盖新选择。核对期间保留上一份画布的来源标签；核对成功后，在同一同步提交段替换新的 iframe 节点并更新来源标签。load 回调同时核对代次、元素身份与源文本，旧节点或旧选择的事件不能覆盖新状态。失败时保留上一份已核对的画布与标签。

## 零依赖构建与检查

运行时只需要现代浏览器。构建/静态检查使用 Python 3 标准库；控制流程检查使用 Node.js 20+ 内置模块。不安装包、不联网。

安全输出实现使用 POSIX 的 `O_DIRECTORY`、`O_NOFOLLOW` 与 `dir_fd`，当前仅在 Linux、Python 3.12.14、Node.js 24.19.0 验证。Windows 等平台的构建写出没有验证，不应视作跨平台构建承诺；生成的 HTML 是独立浏览器文件。

在本目录运行：

```sh
# 已有交付文件：只读复核源锁、六份源字节与生成结果
python3 build_fixture.py --check fixture.html

# 新构建：必须使用尚不存在的文件名
python3 build_fixture.py --output fixture-next.html

# 原创静态/构建测试与轻量模拟 DOM 控制流程测试
python3 test_fixture.py
node --test test_runtime.cjs
```

输出仅能是本目录下的普通 `.html` 文件名；路径穿越、子目录、现有文件或符号链接都被拒绝。使用独占新建，不覆盖旧文件；写入失败清理本次新建文件。构建器仅读取固定来源，输出限定在本目录。
