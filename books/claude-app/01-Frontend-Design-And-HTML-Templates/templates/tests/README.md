# 模板检查

使用 Node.js 20 或更高版本。在本目录运行 `npm install`，再执行 `npm test`。页面本身不需要这些依赖；测试只读取上一级六个 HTML，不依赖研究工作区或本书其他代码。

测试使用 jsdom 26.1.0 模拟 DOM、定时器、对话框与存储。覆盖单文件结构、脚本语法、输入状态、IME 防误提交、键盘事件、记录与偏好持久化失败，以及隔离预览的字符串与元素结构。结果和六个 HTML 的 SHA-256 写入 `results.json`。

本测试不渲染页面，不执行 iframe 的 CSP，也不代替原生对话框焦点、真实输入法与屏幕阅读器验收。浏览器检查见上一级的 `QA-CHECKLIST.md`。

新增 edge.cjs 覆盖 25 项中断、重复操作与失败恢复检查，包括断点宽度焦点恢复、存储拒绝、标题结构更新与取消边界。连同原有 80 项共 105 项；这些为静态与模拟 DOM 检查。

preview-lifecycle.cjs 另检查 8 项文档替换与失败保留合同，总计 113 项。有效更新重新挂载保持相同 sandbox/CSP 的 iframe；无效输入保留上一份文档。真实浏览器的可见绘制另行验收。

## 文档页目录与搜索恢复

`node editorial-navigation.cjs` 运行 8 项新增模拟 DOM 检查：普通 HTTPS、含异源 `base` 的预览页和 file URL 下的目录归属与搜索定位，以及历史写入被拒后继续聚焦、复用目录说明。页内 URL 基于当前文档构造，不依赖 `base`；历史片段更新是可选增强，失败不妨碍正文定位。file URL 项使用 jsdom 合成环境，不代表真实本地文件浏览器已经验收。

2026-10-15 在云端 Chrome 对固定提交 `513254c6e1e694485f0fb7eee65f404b0fb71f9b` 做了真实 HTTPS 复验：切换文档后四个动态目录保留当前页面地址；点击“拆分复用”仍在该页面；搜索“主题”后点击结果，URL 与焦点均进入 `docs-theme`，搜索结果正确收起。此复验只覆盖这条路径，不代表本地 file URL 或全部模板交互验收。

## 当前章节选择

`node active-section.cjs` 有31项确定性DOM回归。IntersectionObserver只触发重新测量；当前模式的整组实时位置决定当前段，回调条目顺序不决定赢家。目录或搜索定位在滚动位置不变时保留明确目标，主动滚动和布局改变再按阅读线选段。测试模拟几何与帧调度，不代替真实浏览器排版验收。加上前述121项，模板集合共有152项静态/模拟DOM检查。

## 快捷键与焦点归还

`node --test keyboard-focus.test.cjs` 增加19项回归，总计171项静态/模拟DOM检查。聊天模态框内的新对话快捷键不会清空背景草稿；编辑器切换到预览后，焦点从即将隐藏的面板迁到可见标签；轻入口关闭时回到真实唤起控件，原控件已被移除则回到稳定入口。保留原生 dialog 的焦点圈与 Escape 处理，不另造一套 Tab trap。

测试还覆盖 Ctrl/Meta、无效预览、普通按钮焦点、移动导航抽屉、重复打开、自动打开与记录重绘后的回落。jsdom 模拟对话框事件；真实 Chrome 的修复前复现与修复后复验另记在浏览器检查清单。

## 静态预览的内容合同

`node preview-input-contracts.cjs` 增加32项输入回归，总计203项静态/模拟DOM检查。净化后保留的文字或非 STYLE 元素都算静态内容；纯 CSS 色块、分隔线和伪元素布局不再因没有 textContent 被拒绝。只有样式、空白或被全部移除的节点仍拒绝，并保留上一版预览。是否真正可见由浏览器布局决定，不能从有无文字推断。

其他用例覆盖属性/节点白名单、格式异常、大小边界、500层合成结构、错误恢复及iframe替换。CSS中保留的URL由iframe CSP限制，DOM测试只核对策略文本，不能据此声称已经验证浏览器拦截。更深输入在jsdom内部解析栈触发的异常没有算作真实浏览器缺陷。
