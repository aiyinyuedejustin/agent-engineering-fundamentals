# 六个独立 HTML 的令牌同步检查

检查六份单文件模板是否仍内含与共享 CSS 一致的原创令牌，避免主题按钮能切换 `dataset`，但颜色或尺寸副本已经不同步。

## 输入合同

向检查器明确传入本章根目录。它读取：

- `styles/claude-tokens.css`：实际 CSS 声明基线。
- `styles/design-tokens.json`：机器可读的原创角色映射与尺寸档。
- `templates/01-*.html` 至 `templates/06-*.html`：各一份独立模板。

五套配色为 `paper`、`sage`、`ocean`、`plum`、`graphite`，各有 `light` / `dark`。容器上的三个属性必须放在同一个元素：

```html
<main data-ui="atelier" data-palette="sage" data-theme="light">
  <!-- 内容 -->
</main>
```

这些都是原创配方。本检查不使用产品提取色表，也不把 1,341 条静态颜色观测与五套原创配方混为一组。`styles/tokens.css` 中的 `--study-*` 体系不属于此合同。

### JSON 是 CSS 的子集

JSON 提供 90 个颜色值、18 个尺寸值，以及三个系统字体类别。七个公共动作/状态/遮罩变量、阴影、动效、完整字体栈等以 CSS 为准。

无密度属性时，CSS 的控件默认值是 40px；JSON 的 compact 36px / comfortable 44px 是两个明确的密度档，二者不矛盾。字体只核对 JSON 类别与 CSS 最后一级 sans-serif / serif / monospace 回退，不把类别当成完整字体栈。

## 安装与运行

使用 Node.js 20 或更高版本。在本目录运行：

```sh
npm install --ignore-scripts
node check-token-parity.cjs ../..
TOKEN_PARITY_ROOT=../.. npm test
```

`../..` 按 `templates/token-parity/` 的交付位置指向本章根目录；在其他位置运行时，请传入相应路径。直接依赖为精确版本 PostCSS 8.5.30 和 parse5 7.3.0。

检查器只读取输入，JSON 结果写到标准输出，不改 HTML、CSS、JSON 或已有报告。需要保存时由调用方重定向：

```sh
node check-token-parity.cjs ../.. > token-parity-result.json
```

退出码：

- `0`：声明合同一致。
- `1`：存在差异；JSON 列出文件、规则、属性和期望/实际内容。
- `2`：输入或解析错误，或遇到未支持的合同形式；不能视为通过。

现有主题切换测试检查 `dataset`，现有配方测试检查 CSS/JSON 与生成输出；本检查补充六份内嵌副本的同步核对。配套 95 项自测包括 60 个逐页面/配色/主题的颜色漂移反例，以及删声明、重复声明、额外覆盖、作用域、转义、条件、解析边界和 CLI 退出码。自测使用临时夹具，不改输入文件，也不计入原有模板交互测试数量。

## 适用边界

这是**静态声明与选择器合同检查**，不是浏览器级联或绘制验收。它不执行脚本、不运行 `getComputedStyle`、不检查像素、字体可用性、布局、真实对比度、输入法、辅助技术或 `file://` 行为。

- parse5 正确区分活动 STYLE 与 JavaScript 预览字符串；未实例化 TEMPLATE 和 iframe 内容不属于父页面初始样式表。
- 外部 stylesheet LINK、CSS `@import`、含令牌的条件/非 CSS STYLE、转义声明名或 at-rule 名，以及 `@property --ui-*` 注册均显式报错。检查器不会加载外部 CSS，也不对未建模输入报告通过。
- 不跟踪脚本之后注入的样式、CSSOM 修改、外部组件与用户样式；不核对所有普通 CSS 消费者或实际继承结果。
- 比较保留内部空格、大小写、选择器分组、顺序、值与重要性。视觉等价的 HEX/RGB 改写、规则合并或重排也可能产生差异，应人工评审；注释与选择器列表分隔处的格式变化允许通过。
- CSS 是当前声明基线，不是永久冻结的产品真值。有意改配方时，应同步 JSON 与六页；有意改变五套配色或 16 组规则的结构时，也应更新检查器和自测。

真实浏览器矩阵应独立验证各配色/主题下的实际应用、嵌套主题、原生控件、强制颜色与绘制结果，不能从本检查的通过状态推导。
