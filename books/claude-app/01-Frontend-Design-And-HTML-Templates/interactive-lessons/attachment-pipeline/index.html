      每一步都有原因
      事件记录
        这份记录只保留合成状态变化。实时播报使用独立的简短状态区。
        

        01
        身份比文件名更早建立
        同名附件也有不同 client ID。槽位在开始处理时就确定，完成速度不能改变输入顺序。对应卷五 5.1、5.3 与 5.11。
        02
        字节、字符、token 分开
        “这是中文便签”是 6 个字符、18 个 UTF-8 字节；“Hi 🌱”的 JavaScript 长度为 5、UTF-8 为 7 字节。本课没有 tokenizer。对应 5.4 与 5.11。
        03
        取消不能替代归属检查
        写回时同时检查账户、草稿、代次、client ID 与尝试编号。服务端可能早已完成；本课只证明本地结果不会重新挂回。对应 5.7–5.9。
