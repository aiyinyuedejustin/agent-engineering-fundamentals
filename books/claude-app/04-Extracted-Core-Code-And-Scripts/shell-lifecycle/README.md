# 导航归属与退出结算实验

本目录为原创最小模型，不依赖 Electron、Claude 安装包或账号。Node.js 20+ 下运行：

```sh
node --test lifecycle.test.mjs
```

12 项测试围绕两个容易混淆的问题：旧页面晚到的回调如何失效，以及退出等待到期以后还能宣称什么。

- `NavigationOwner.begin` 发出不可变 ticket；`settle` 只接受当前 ticket 的第一次结算。相同字段的伪造对象也不拥有这次导航。
- `dispose` 撤销归属。它不停止真实网络请求，实际适配器还需取消订阅与 AbortController。
- `settleShutdown` 同时启动具名清理项，单项抛错不阻止其他项。到期返回的是协调快照，未完成项仍可能继续运行。
- `flush` 是后续独立阶段，本模型没有给它另加超时，所以 cleanup 的 deadline 不是整个函数的最大全程时长。真实应用应为持久化与最终退出另设策略。
- 这里不模拟 Electron 的事件顺序、操作系统进程结束、磁盘原子性或浏览器安全边界。

扩展练习：给真正可取消的任务传入信号，并分别记录“发出取消”“任务确认停止”“外部资源释放”。不要把三个时间点合并为一个 cancelled 布尔值。
