# 研究方法：从安装包到可核验的结论

## 先固定对象，再决定工具

本次对象是官方 Claude Desktop 2.37337.1。Linux amd64 的官方包经签名索引与 SHA-256 核验后，使用 `dpkg-deb -x` 解包，没有安装或运行应用。REA 使用固定发布版本 6.5.0。

[获取与版本记录](data/acquisition-manifest.json)保存工具包摘要和目标包身份。Linux 的验证链是：官方文档公布的签名指纹 → 仓库 InRelease 签名 → Packages 索引摘要 → 包大小与 SHA-256。单独从一个下载地址取到文件，不等于完成这条验证链。

## REA 实际做了哪些事

1. `inspect-artifact` 对 app.asar 建立文件与结构清单。
2. `extract-artifact` 在默认完整性策略下提取可分析内容。输出目录由工具生成，应从结果 JSON 读取，不能猜。
3. `analyze-javascript-application` 对明确选定的 JS 文件做有界静态分析，建立关系与候选入口。
4. 原创解析脚本补充 CSS 自定义属性、字体元数据、组件选择器与条件分析。
5. 人工/独立审查把候选位置转成带范围的结论，再检查正文与演示是否忠实表达。

本次第一轮 JS 分析仅选择三个文件，结果有明确的 partial coverage，不能称为恢复了整个应用。REA 不是 CSS 设计规范生成器，也不能把推断自动升级为运行事实。

命令模板（路径替换为已核验的输入）：

```sh
rea inspect-artifact /path/to/app.asar --format json --full-output
rea extract-artifact /path/to/app.asar --format json --full-output
```

JavaScript 分析应先看本版本帮助，限制文件集合、时间与内存，再扩大到已发现的相关入口。不要对上百 MB 的包反复无界解析，也不要以输出 JSON 的大小衡量理解程度。

## 一条证据需要什么

- 样本：平台、架构、版本、原始包摘要。
- 文件：包内相对路径、大小、SHA-256。
- 定位：零起点 UTF-8 字节范围，或很短的 anchor 与出现次数。
- 语义：它属于哪个组件、哪种主题、哪个条件分支。
- 结论类型：静态事实、公开说明、实际观察、推断或原创适配。
- 缺口：哪些条件还没有测量，哪些替代解释仍成立。

一个真实纠错例子：Dialog 与 Tooltip 都含有 `scale-[0.98]`。字符串与偏移验证可以全部通过，但若 anchor 指向 Tooltip，就不能支撑 Dialog 的结论。独立审查找出这个错误后，我们把定位改到 Dialog 的 transition 定义，并重新验证。**字节验证和语义验证是两道不同的检查。**

## 多平台对照不能只看版本号

版本号相同只是起点，还要对实际文件集合与字节做比较。UI 资源相同，也不代表原生窗口、菜单、系统权限、更新器或实际字体回退相同。分别维护共享资源、平台外壳和运行时效果三层结论。

REA 如因完整性检查停止，就保留失败及范围，不为了完成报告而放宽校验。格式不支持时，可使用合适的只读档案工具处理外层格式，再对所得文件建立独立身份。工具路线变化应记录，不能把其他工具的成果写成 REA 的能力。

## 发布与复现

公开资料只保留精选观察、原始来源链接、文件哈希、短定位和原创实现。临时签名 CDN URL、工作区绝对路径、完整提取图、安装包、字体与应用脚本不属于书的交付物。

演示代码目前通过模拟 DOM 与静态检查；这不覆盖真实浏览器布局、原生 dialog/inert、输入法、屏幕阅读器、高对比模式和缩放。测试报告中的通过数量，只回答其明示的断言，不提供整个产品的正确性保证。

### 复核这份书的精选证据

准备好相同版本、已解包的官方资源后，可运行仅使用 Python 标准库的验证器：

```sh
python3 scripts/verify_evidence.py \
  --resources /path/to/resources \
  --asar-root /path/to/extracted-app-asar
```

它只读取指定目录，核对文件大小与摘要、188 项声明定位、32 项组件 CSS 选择器定位和 57 个 JavaScript 短锚点。data 中 `ion/` 映射到 resources 下的 `ion-dist/`，`asar/` 与 `app.asar/` 映射到已经提取的 ASAR 根目录。

不同版本的哈希不匹配会失败，这是预期行为。不要通过关闭检查把新版本强行套进旧结论。即使全部通过，Dialog/Tooltip 一类语义归属仍需独立阅读上下文。
