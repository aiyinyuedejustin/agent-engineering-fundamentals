# 原创模型的七条边界合同

正常路径跑通以后，最值得检查的是取消、溢出、输入别名和重复回调。这里的代码与回归测试均属于本书的原创教学实现。

| 边界 | 最小反例 | 实现应保证什么 |
|---|---|---|
| 取消中的重入 | cancel 回调同步提交新请求 | 旧任务的 fallback 不能覆盖新内容；取消后再次核对 epoch 与 sequence |
| 缓存记账 | 两个有限权重相加得到 Infinity | 加入前腾出容量，拒绝不可表示的合计；删除后重新核算有限条目 |
| 审批序列化 | 数组覆盖自己的 map 方法 | 不调用输入对象携带的方法；只编码已检查的数据属性 |
| 几何输入 | 稀疏矩阵、极小缩放、乘法溢出 | 逐项验证稠密输入；对不可表示的变换明确失败，不传播 NaN |
| 音频批次 | 一个批次的末尾样本无效 | 先快照并验证整个批次，再改变分帧状态；RMS 使用缩放平方和 |
| 目标身份 | 调用者在保存后修改目标对象 | 保存独立快照，验证必需身份和时钟，再接纳异步结果 |
| 退出定时器 | 毫秒数超过 2³¹−1 | 启动清理之前拒绝越界，避免定时器被运行时夹成极短等待 |

## 怎么跑

在本目录执行：

```sh
python3 -B run_book_tests.py --skills
```

四组模型的原有 125 项测试保留，新增 56 项边界回归，共 181 项；总命令还会运行本书其他模型。Skills 中的独立副本重复验证可移植性，不计为另一套算法。

- [流式性能：40 项](streaming-performance/README.md)，含取消重入和权重溢出。
- [安全边界：68 项](security-guardrails/README.md)，含数组属性、一次性审批与无效时钟。
- [原生、音频与几何：61 项](native-voice-geometry/README.md)，含横纵不等比例缩放和非法批次的原子拒绝。
- [窗口生命周期：12 项](shell-lifecycle/README.md)，含定时器范围与截止前后的结果。

加固输入并不等于扩大支持范围。例如拒绝自定义原型数组，意味着这个合同只接受普通稠密 JSON 数组；不能据此宣称支持任意 JavaScript 对象。缓存重算采用 O(n) 的清晰实现，适合有界教学模型；若迁移到大容量缓存，应先定义整数权重单位与数值上界，再优化记账。
