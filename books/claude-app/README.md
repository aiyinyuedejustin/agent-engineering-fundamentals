**当前是持续研究稿，不是已完成的产品复刻，也不是 Claude 官方文档。** 研究样本以 Claude Desktop 2.37337.1 为主，日期为 2026-10-14。具体结论注明平台、版本、条件与验证方式。

## 证据边界

- **包内静态观察**：证明相应代码或资源存在，不保证当前账号、功能开关或远程页面使用它。
- **公开文档与截图**：按来源与时间解释。帮助页今天更新，不等于截图今天拍摄。
- **运行时观察**：只用于实际运行与测量过的具体表面。目前未完成登录后的 Claude Desktop 运行验证。
- **原创示例与建议**：是本研究的实现选择，不写成 Claude 内部实现。

本仓库只发布原创分析、精选事实、定位信息与原创演示代码，不分发 Claude 安装包、完整脚本/CSS、字体或截图资源。官方产品名称仅用于指明研究对象。
