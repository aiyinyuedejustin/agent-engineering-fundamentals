# 代码来源与模块职责

本目录是原创整合与实现，不是从产品提取的实现源码。

- `toolkit/css_scan.py`：复用已有原创 color-tools 中的字节级块/声明扫描方法，增加结构/声明数量限制、未闭合注释与多余闭合符检查，保留引号选择器中的注释样式文本；其余颜色求值和 HTML 色表能力不复制。
- `toolkit/safeio.py`：原创本地字节读取、受限 ZIP 子集检查和受限展开流程。
- `toolkit/literals.py`：原创低依赖词法/JSON 候选筛查，不是通用 AST、JSON Schema 验证器或作用域绑定器。
- `toolkit/inventory.py`：原创确定性目录快照、来源锚点、扫描策略与覆盖记录。
- `toolkit/diffing.py`：原创值集合匹配、文件差分、待核候选分层与 Markdown 输出。
- `reverse_toolkit.py`、`run_tests.py`：原创 CLI 与测试入口。
- `tests/fixtures/`：原创合成数据，不来自产品。

已有研究的特定版本旗标、ASAR、工具契约分析脚本提供了问题划分和证据边界参考；其硬编码版本路径、混淆别名和第三方 AST 依赖没有移植到默认工具箱。需要那些更深的分析时，应重新核实输入版本、作用域绑定与实际工具链，不把通用字符串匹配升级为完整产品事实。

REA 仅是文档中可选的外部工具，无代码或依赖捆绑。本目录不授予任何第三方产品源码、安装包、字体或商标的使用/再分发权。
