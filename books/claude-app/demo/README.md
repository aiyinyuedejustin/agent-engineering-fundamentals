# 留白 · 可交互界面研究

> 独立研究示例，非 Claude 官方产品。

这是一个原创、中文、离线可用的桌面 AI 界面设计学习示例。它把静态证据中的部分色彩数值，放到独立编写的语义变量、组件与交互中，便于观察“同一套设计原则如何进入实现”。它不是 Claude 客户端，不提供模型服务，也不是官方源码或像素级复刻。

## 运行

直接用现代浏览器打开 `demo/index.html`。不需要安装依赖、启动服务器、登录、联网、API key 或编译。

若希望通过本地 HTTP 查看，在仓库根目录执行：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/demo/`。服务仅用于本地静态文件查看，不是应用后端。

兼容目标为支持 `dialog`、CSS 自定义属性、`inert`、`matchMedia` 与 `dvh` 的现代 Chromium、Firefox、Safari。页面不加载外部字体、图标包、CDN、分析脚本或其他远程资源。

## 可以操作什么

- 浅色 / 深色主题：切换后更新整页语义映射与色板值。仅主题选择尝试保存在本机 `localStorage` 中；存储不可用时仍可使用。
- 导航：对话与阅读、组件图谱、语义变量；窄屏导航使用遮罩、背景 `inert`、焦点循环和 Esc 退出。
- 本地模拟对话：输入并发送、停止生成、模拟失败、保留输入后重试。所有回复均为预置文字；任何输入都不会被发送到网络。
- 研究注释：结构 / 色板 / 状态三个键盘可导航标签页；切换组件边界；检查当前状态。
- 内容预览与说明窗口：浏览器原生模态窗口，支持 Esc、背景点击关闭和触发按钮焦点恢复。
- 输入检查：验证长度后显示具体错误，并保持原输入。
- 复制示例文字：剪贴板不可用时选中文字，让用户手动复制。
- 所有对话只存在于页面内存中。刷新、重置或“新的观察”会恢复初始演示。

## 证据与原创提案的边界

### 观察到的事实

本研究选用的部分颜色字面值，可在所检 Claude Desktop Linux `2.37337.1` 安装包的静态 CDS CSS 声明中找到：

- 浅色 surface 0 / 1 / 2：`#f9f9f7` / `#fcfcfb` / `#ffffff`
- 深色 surface 0 / 1 / 2：`#0b0b0b` / `#151515` / `#1a1a19`
- 浅色主要 / 次要文字：`#0b0b0b` / `#52514e`
- 深色主要 / 次要文字：`#f0efec` / `#c3c2b7`
- Clay：`#d97757`；蓝色交互色角色中的一个值：`#2a78d6`

这些只是声明存在的证据。它们不能证明实际 DOM 匹配、加载顺序、级联后的 computed style、运行时覆盖、用户默认设置或功能可用性。不能把示例截图当作官方客户端截图。

`evidence.js` 保存源文件名、SHA-256、选择器、块编号与字节范围，供与完整研究文档交叉检查。范围从 0 开始，UTF-8 字节，末端不包含在内。页面只分发事实摘要，不分发提取的样式表或应用源码。

### 本研究独立决定的部分

- 所有 `--study-*` 语义名称与其组件用途
- 页面品牌“留白”、两笔几何标记、布局、内容、图标、组件类名、DOM、状态机
- 通用 .study-button 最小高度 40 px（分段按钮、主题切换和注释链接另有尺寸）、导航和阅读区宽度、响应式断点、消息样式
- 系统无衬线 / 系统衬线的字体替代与中文阅读策略
- 辅助文字加深、输入边界加强、错误与成功配色
- 操作使用中性色，Clay 只做有限提示；焦点独立使用蓝色
- 动效与等待时长；减少动态效果偏好下取消逐字呈现

因此，即使某个数值来自静态观察，把它用于本示例某个组件的决定仍是“原创映射”。色板明确区分“观察值 · 原创映射”与“研究新增值”。

## 可访问性实现意图

- 原生按钮、表单、标签、`disabled`、`aria-invalid` 与可见焦点
- 中文输入法组合期间不响应 Enter 发送；Shift + Enter 换行
- 标签页左右箭头 / Home / End 导航
- 模态窗口使用原生 `dialog.showModal()`，关闭时恢复焦点
- 窄屏导航提供背景隔离、焦点循环、Esc 与点击遮罩关闭
- 流式内容不逐字打断屏幕阅读器，仅播报状态完成 / 中断
- 停止与重置取消计时器并使过期回调失效
- 错误不仅通过颜色表达，包含标题、说明、图标和重试操作
- 表单边界独立于装饰分隔线；高对比模式保留边框与开关选中提示

这些是实现设计，不等于已经完成完整 WCAG 合规审计。请以仓库最终验证报告为准，尤其关注实际字体、缩放、移动端、输入法与辅助技术差异。

## 手动检查路径

1. 使用 `file://` 直接打开；确认没有网络资源、错误或缺失样式。
2. 切换浅色 / 深色，查看结构 / 色板 / 状态与组件图谱；检查文字和控件边界。
3. 输入中文，组合候选时按 Enter；应只确认候选，不发送。再按 Enter 应发送。
4. 生成中停止、连续点击、切换章节、重置；等待后不得出现陈旧回复。
5. 启用“下一次发送模拟失败”；失败后应保留输入，重试不得重复添加用户消息。
6. 关闭 / 禁用存储与剪贴板权限，确认主题仍可切换，复制提供手动回退。
7. 用 Tab 打开并关闭模态窗口；确认焦点回到触发按钮。
8. 窄屏展开导航，循环 Tab、Shift + Tab、按 Esc；背景应不可聚焦。
9. 启用系统“减少动态效果”；模拟回复应一次呈现，控件无过渡动效。
10. 在 320、390、768、1440 px 宽度与放大字体下检查无横向溢出；使用高对比模式检查开关与边界。
