# Claude App 研究资料使用流程

## 何时使用

需要理解这份研究书、核验具体发现、生成原创 UI 适配、或扩展一个新版本的证据时使用。它不授权登录、读取私有数据、执行目标应用或发布第三方资源。

## 流程

1. 从仓库 README 确定所需章节及完成状态。
2. 明确问题涉及的表面：桌面壳、主聊天页面、Quick Entry、Code，还是原创建议。
3. 读取章节，然后仅加载04-Extracted-Core-Code-And-Scripts/evidence/data 中的相关文件。记录样本版本、平台与条件。
4. 回答事实时引用 claim 或 observation ID、包内文件与来源；同一个值属于多个系统时分别说明。
5. 写代码时使用01-Frontend-Design-And-HTML-Templates 中的原创交互示例与样式 作为学习样本，先选择语义角色和状态，再选择视觉数值。不要复刻第三方标志、字体或私有实现。
6. 改动后运行与改动范围匹配的测试。模拟 DOM、静态检查、真实渲染和辅助技术检查分开报告。
7. 若发现证据冲突，保留冲突并列出下一项可区分解释的检查，不把它自动合并成统一规范。

## 输出约定

回答按“结论 → 适用范围 → 证据 → 原创应用建议 → 未验证项”组织。只列与问题有关的限制，避免重复整本书。不要把代码存在、文档承诺、截图印象和实测结果混为一谈。
