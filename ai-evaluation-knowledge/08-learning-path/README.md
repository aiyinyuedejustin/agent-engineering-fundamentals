# Learning path

**Status: scaffold only. No completed curriculum or learner assessment is claimed.**

Build a progressively deeper path through evaluation concepts and implementation, linking each step to reviewed primary sources and case artifacts. Adapt the order as evidence develops.

Initial structure to refine:

1. Measurement goals: constructs, task validity, metrics, and interpretation.
2. Benchmark anatomy: data, splits, prompts, model interfaces, graders, and aggregation.
3. Implementation reading: task/configuration inspection (D2), followed by source-level execution traces (D3).
4. Reproducibility: protocol matching, variance, contamination, and provenance.
5. Controlled practice: actually executed experiments (D4), with retained logs and limitations.
6. System design: architecture decisions, trade-offs, and evaluation-infrastructure requirements.

For each future module, include prerequisites, learning objectives, source/evidence IDs, concrete reading tasks, an applied exercise, and a way to test understanding. These are planned topics, not a claim of verified teaching materials.
