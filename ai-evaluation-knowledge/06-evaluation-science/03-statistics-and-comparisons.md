# 统计比较：不要把小数点当证据

## 1. 先说清楚不确定性来自哪里

至少存在四个层次：

1. **任务抽样**：这一批题是否代表希望推广到的任务总体？
2. **模型采样**：相同题目重跑会不会得到不同答案？
3. **评分噪声**：人工或模型 judge 是否给出不同判决？
4. **实现与环境变化**：工具、依赖、超时和供应商服务是否改变了结果？

如果只想描述固定的 100 道题、固定输出、固定评分器，平均分就是该有限集合的描述值。想推广到未来任务时，需要额外的抽样与代表性假设。一个置信区间无法修复样本偏差、污染或测错构念。[Miller §2](https://arxiv.org/html/2411.00640v1#S2)、[有效性审查](https://arxiv.org/html/2511.04703v1)

## 2. 单模型均值的基本计算

对 n 个独立任务的数值分数 s_i：

- 估计均值：`mean(s)`。
- 标准误：`sample_sd(s) / sqrt(n)`。
- 大样本近似 95% 区间：`mean ± 1.96 × SE`。

二元正确率可用二项模型，但不要把伯努利标准误直接套在 token F1、部分得分或重复采样后的题均值上。靠近 0/1、小样本或稀有失败时，正态区间可能失真，应考虑适合二项数据的 Wilson/精确区间，并说明采用的方法。

零失败也不是零风险。100 次独立试验均无失败，在同分布二项模型下，失败率的一侧 95% 上界是 `1−0.05^(1/100) ≈ 2.95%`。此处条件是独立、同分布且任务覆盖合适，不能拿来为任意部署环境担保。

## 3. 比较模型优先用逐题配对差

同一批题对 A、B 的分数为 a_i、b_i，令 `d_i=a_i−b_i`，直接计算 `mean(d)` 与 `sd(d)/sqrt(n)`。

基本恒等式是：

`Var(A−B) = Var(A)+Var(B)−2Cov(A,B)`。

因此相同总正确率，不意味着相同差值区间。也不要用“两条独立置信区间是否重叠”替代对差值的直接检验。配对通常在错误模式正相关时更精确，但**不是数学上永远更窄**，负相关时可以更宽。[Miller §4](https://arxiv.org/html/2411.00640v1#S4)

### 本地 D4 演示

两个构造数据集都包含 1,000 题，A=72%、B=70%：

| 数据集 | 两模型判对错不同的题数 | 差值 95% 配对近似区间 |
|---|---:|---:|
| 高重合 | 60 | +0.49 至 +3.51 个百分点 |
| 低重合 | 560 | −2.64 至 +6.64 个百分点 |

总分完全相同，但前者有更强的差异证据。第二个构造刻意产生较低相关性，用来展示边界，不代表真实模型通常具有这种相关结构。[原始 JSON](experiments/results/statistical_diagnostics.json)

二元配对结局还可用 McNemar 类检验，尤其要关注 A-only 与 B-only 的 discordant 对；是否使用精确形式取决于样本与检验协议。不同检验不是可任挑一个显著结果的菜单，应预先选定。

## 4. 多题共用同一材料时，不能假装完全独立

同一篇文章的多道问答、同一个数学题的多个译本、同一个仓库的近邻问题、同一会话中的多个回合，可能形成 cluster。

应根据实际抽样过程在合适层级计算 cluster-robust SE，或整簇重采样。配对 bootstrap 必须把同一任务的 A/B 结果一起重采样。对于同一任务的多次模型运行，也不能把所有行当作独立新题。

本地演示包含 100 个独立 cluster，每簇十条完全相同的结局：

- 误把 1,000 行当独立样本，SE=1.55 个百分点。
- 以 100 个簇均值计算，SE=4.92 个百分点。
- 忽略聚类把标准误缩小了约 3.18 倍。

行 bootstrap 的 95% 区间约 [0.569,0.631]，簇 bootstrap 约 [0.50,0.69]。两者都“做了 bootstrap”，只有后者对应这个合成数据的抽样单位。[实验](experiments/results/statistical_diagnostics.json)

簇数很少、簇大小不同、跨簇相关或非随机抽样时，还需要更谨慎的设计与推断。不存在“只要 bootstrap 就正确”的保证。

## 5. 多跑几次能解决什么，不能解决什么

把每题重复 k 次后先求题均值，能够减少模型随机采样噪声，但不会消除任务难度与题集选择的不确定性。近似分解：

`Var(总体均分) = Var(逐题真实均值)/n + E(题内采样方差)/(n k)`。

当第二项已经很小，继续重复旧题收益有限；增加独立题目可能更有效。实际还要考虑题目制作成本、推理成本，以及评测真正关心的是一次成功率还是多次可靠性。[Miller §3](https://arxiv.org/html/2411.00640v1#S3)

不要为了压低误差条而改温度。温度、采样和推理预算改变的是被测系统；应按部署条件或明确比较条件固定，并单独研究敏感性。

## 6. 功效与实际意义

先定义最小值得采取行动的差值 δ。大样本配对设计下，粗略样本量关系为：

`n ≈ (z_(1−α/2)+z_(power))² × Var(d) / δ²`。

方差可从先导实验估计；若有聚类，要按相应设计修正。样本量随希望检测差值的平方倒数增长，因此检测 1 个百分点通常比检测 5 个百分点困难得多。

不要把论文中的示例“约 1,000 题”变成通用标准。需要多少题取决于差值、方差、采样单位、显著性水平、功效、重复次数和检验数量。

**原文算术核查：** Miller v1 §4.2 的均匀分布例子给出 Var(A)=Var(B)=1/12、相关系数 0.5，却随后把配对方差写成 1/9。直接代入协方差恒等式应得到 1/12，即相对独立情形减少 50%，而非文中示例的 1/3。本目录保留其通用推断框架，但不沿用这一有误的示例数值；已用本地计算验证恒等式。[固定 v1](https://arxiv.org/html/2411.00640v1#S4.SS2)、[验证 JSON](experiments/results/statistical_diagnostics.json)

## 7. 排名和反复调试带来的选择偏差

- 同时比较许多模型/提示词，至少应说明比较数量及多重检验处理。
- 在同一验证集上反复挑最好的配置，该集合已经参与选择，不能当完全未见测试集。
- 选择后的最佳分数有乐观偏差。保留独立最终测试集，或采用合适的嵌套设计。
- 排名差异很小时，报告差值和不确定性，不强行制造第 1 与第 2 的确定分界。

独立进行 20 个 α=0.05 的零假设检验，至少一次假阳性的概率约为 64.15%。这只是独立性演示，实际相关检验不必等于此值。

另一项本地模拟让 20 个候选都具有真实成功率 70%，每个只测 200 题，再选择观察值最高者。2,000 次模拟中，被选者平均观察分为 75.95%，约高估 5.95 个百分点。这不是模型真的更好，而是选择噪声获胜。[可复现脚本](experiments/statistical_diagnostics.py)

## 8. 报告最小集

报告：样本数、独立簇数、重复次数、配对方式、点估计、差值区间、区间方法、显著性协议、实际意义阈值、无效/缺失数、成本与延迟，以及预先指定与事后探索的分析区别。

统计显著不等于足够有用；不显著也不等于两个模型等价。若要声称“不劣”或“等效”，需要预先定义可接受差距及相应检验设计。
