# 音频与翻译模型报告：协议变化怎样改变一句“更好”的含义

收集日期：2026-11-06。新增四篇官方报告的限定章节阅读；均为D1/L1，没有运行模型、听取音频、核验真实评测任务或独立复现分数。本笔记是原创分析，43条新增数值记录见ME148–ME190。

## 1. Step-Audio 2：同一张能力图横跨多种判分链

来源：[Step-Audio 2 v1](https://arxiv.org/html/2507.16632v1)，2025-07-22版，§3.1与§4.1–4.6。读取的是v1；不把当前无版本abs页面的后续修订正文混入。

ASR采用语言相关的编辑错误单位：四套英语数据平均WER3.18%，六套中文数据平均CER3.11%。这两个数字不能合并成一种“语音理解正确率”，也不是按所有单词合并后的统一微平均。报告没有在已读段落给出合并分母。

MMAU明确为 **v05.15.25 Test-mini**，Step-Audio 2的总体分数77.4。基线来自原论文、MMAU官网或作者重跑三种渠道；由于数据更新，部分模型被重测。由此不能假设整张表的所有API快照和协议完全一致。后来的MiMo报告中Step-Audio2-mini是另一模型名，不能把mini的72.73当作同一模型在同一套任务上退化。

Step-Audio Paralinguistic是550个语音样本、11个维度的作者自建测试。原始片段短于30秒、统一24kHz；若干任务用原语音克隆合成问题、拼接前后位置，另外若干任务还混合声音与合成语音。评分链先把回答ASR为文本，再由文本LLM判定，平均76.55。它可以测模型是否答对副语言信息问题，不能仅凭该分数推导生成语音的自然度或低延迟体验。数据/代码虽有公开链接，本轮没有读取其任务源码。

Step-Audio Toolcall每种工具构造200个3–6轮正例脚本及等量负例，再合成语音。Qwen3-32B用于自动检查输出；对照的Qwen3-32B模型接收文本，Step-Audio 2接收语音。以audio-search为例，trigger precision/recall分别为86.8/99.5与67.5/98.5。触发、工具类型、参数提取是不同指标，不能把某一层的100%写成端到端工具调用100%；跨模态对照也不属于严格同输入的模型比较。

URO-Bench使用Whisper转写与GPT-4o-mini判分，basic/pro分别有16/20个数据集。Step-Audio 2中文basic/pro为78.86/70.83，英语为79.03/60.25。语言、难度、子集组合和评分器都要随结果保存。没有测双工打断、真实网络时延或长时间会话稳定性，不能把这些汇总分当作电话助手体验总分。

## 2. MiMo-Audio：输入、历史和输出模态都能变化

来源：[MiMo-Audio v1](https://arxiv.org/html/2512.23808v1)，[arXiv提交历史](https://arxiv.org/abs/2512.23808)确认为2025-12-29 v1。已读§3.3–3.4、§4.3–4.4、§6及表4/6–9。

SpeechMMLU不是未经改变的完整MMLU：作者按学科与长度过滤为8549条、34个学科，再用商业TTS构造相同题目的T2T、S2T、T2S、S2S四种条件。Base模型采用5-shot，四种得分为72.5、69.5、71.5、69.1。这个设计适合研究同题跨模态代价，但不能把结果直接并进任意原始MMLU排行榜。另一些speech-to-speech能力演示用16-shot，与这里的5-shot分开。

Instruct的MMSU显示一个有用的子项反转：开启Think后总体61.70→62.88、perception46.86→51.71，但reasoning76.98→74.79。总体提高不意味着每项提高。作者在局限中也说明thinking会改善部分speech任务，却可能因幻觉损害sound/music理解。这里是报告观察，不是本研究的机制实验。

Big Bench Audio的speech回答经Whisper-Large-V3转写后由GPT-4o-mini评价。表8中MiMo的S2T/S2S为72.90/60.20，对照 `gpt-4o-audio-preview-2024-12-17` 为70.20/67.20。正文概括为MiMo“second only to GPT-4o”，但表格中的两个条件排序不同。本记录保留表格的具体模式，不照搬一个全局名次。

MultiChallenge Audio先删除含大量公式、表格、URL等非口语格式的原任务，再用250种声音池合成。其S2T条件的历史是文本，S2S条件的历史全是语音，MiMo得分15.15与10.10。因此两列不只是同一输入换一种输出；难度差还包含历史表示与转写/生成链。过滤后的语音任务也不等于完整文本MultiChallenge。

语音生成的SeedTTS用ASR转写后WER判断内容；InstructTTSEval另用Gemini评价风格指令符合度。WER、声音风格、自然度不是同一个构念。报告把包括AISHELL在内的ASR评价统称WER，已读部分未交代中文分词单位，本轮不擅自改写成CER或拿它与Step-Audio的中文CER直接相减。

作者明确披露音色不连续、音质不稳定、误读、系统提示遵循不一致，以及复杂符号/公式发音和风格控制困难。这些局限与高内容问答分数可以同时成立。

## 3. Hunyuan-MT：训练奖励、独立指标和人评要分开

来源：[Hunyuan-MT v2](https://arxiv.org/html/2509.05209v2)，[提交历史](https://arxiv.org/abs/2509.05209)为2025-09-05 v1、2025-09-09 v2。已读§3.2–3.3、§4.1–4.3、§5.2–5.3与表4/10。

训练的质量奖励包含XCOMET-XXL和DeepSeek-V3-0324按GEMBA风格提示给分，另有术语与重复惩罚。评价也使用XCOMET-XXL。因此该指标不是完全独立于训练目标的外部检验。这个关系提示需要独立指标及人评交叉验证，但单凭共用指标不能断言出现reward hacking或数据泄漏。

在Mandarin↔Minority测试中，Hunyuan-MT-7B相对Gemini-2.5-Pro：

- XCOMET-XXL：0.6082 vs 0.5811。
- CometKiwi：0.4162 vs 0.5418。

两个神经指标给出相反排序；不能只挑第一个就写“少数民族翻译全面领先”。这些也不是正确率或人类偏好概率。低资源语言的指标校准、具体语言权重和错误类型仍需进一步检查。

WMT24pp的结果使用29个语言对，是WMT25推荐开发集的选取。Hunyuan-MT-7B XCOMET0.8585，Chimera0.8787。Chimera接收多个候选翻译再融合，是额外候选生成与融合的系统条件，不是相同计算预算的单次decode。报告中的6候选模板是一个提示示例，不能替代所有成绩的精确总token/时延预算。

人工评价采用0–4分、关注预先标注的易错点、准确性、流利度和地道性。表10对Hunyuan-MT-7B给出Avg3.189。本文保留作者报告的Avg，不假定两个方向样本数量相同或自行重算。样本数、方向权重和置信区间未在已读段落确定，不能把几百分之一分的差异当作统计显著差异。

## 4. HY-MT1.5：相同模型、不同数据切片，不应画成退步曲线

来源：[HY-MT1.5 v1](https://arxiv.org/html/2512.24092v1)，已读§2.2及§3.1–3.5。arXiv页面日期为2025-12-30，早先发现的PDF封面为2026-01-01；分别保存提交页日期与封面日期，不强行视为同一天的发布事件。

新报告将WMT部分换成 **WMT25 human-evaluation set的13个语言对**。同一个旧模型HY-MT1.0-7B（报告说明就是Hunyuan-MT-7B）得0.6023，而旧报告WMT24pp为0.8585。这两个数没有同数据集条件，不构成模型退化的证据。新报告内部的1.8B为0.5308、7B为0.6159，可在该报告明确的切片上理解，不能横跨两张表抹掉版本。

一些商业翻译器的表格星号表示只在支持的语言上计分，约半数语言不支持。因此“表内更高”还可能伴随覆盖面不同，不能默认为完整相同样本。

速度测试是100个中文文本顺序翻译成英文，平均输入50token，日常与一般商务领域。1.8B/7B平均response time为0.18/0.45秒。已读段落未说明硬件、输出长度、计时起止、网络路径或并发负载。它不是首token延迟，也不是高并发吞吐、手机端实测或双工语音端到端延迟，不能与Qwen3-Omni的first-packet理论表直接排序。

量化表中FLORES的ZH↔XX XCOMET：原1.8B为0.8361、FP8为0.8379、Int4为0.8060。没有不确定性时，前两个微小差值只能说明点估计接近，不能证明量化提升翻译能力。该表没有同时提供设备显存与速度，不能拼接为未经测量的部署性价比。

## 5. 可以复用的记录规则

1. 音频成绩至少记录输入/历史/输出模态，ASR系统与judge快照，任务过滤和合成方式。
2. 原版数据集、改版、过滤版和衍生语音版分别登记；只有名字相近不足以比较。
3. 感知、内容问答、风格遵循、自然度、端到端对话完成和时延分别解释。
4. reward中用过的指标，与独立指标及人评分别保存；不要一边抹去依赖，一边无证据指控作弊。
5. 候选融合、多轮推理或工具系统应记录总计算预算，参数量相同不等于成本相同。
6. 发现正文与表格不一致时保留具体单元格、条件和版本，不自行发明一个折中数字。

本轮仍是收集中的专题分析，未形成跨模型总体排名。数值均来自作者报告，没有升级为独立复现证据。
