## 不应忽略的限制

1. 日期保留来源精度，不为仅有日期的记录伪造午夜精确时间。报告更新日、模型首发日、代码commit时间是不同概念。
2. 同一benchmark名称下，子集、任务版本、推理budget、工具、harness、上下文管理、用户模拟器、judge、答案parser与聚合方法可能不同。未知配置保持未知，不假定一致。
3. v1的日期异常仍未消除：DeepSeek-V4源页面提交日与arXiv编号月份不一致；Gemini3Pro索引和当前PDF版本日不同；GPT5网页与PDF封面日不同；KimiK2有v2修订。
4. Opus5.5部分分数含安全fallback或筛选任务集，是系统级或子集结果；Step3.5正文与附录部分重复数不同；MiniMax-M1的40k/80k同时改变训练阶段，均非干净的单变量模型能力比较。
5. 报告作者做过的复现不等于本研究独立复现。外部baseline重新运行、引用或fallback都已在对应观察中说明。
6. 没有私有用户数据或原始长篇报告拷贝。表格分数、来源书目信息和有限事实提取服务于原创分析。
