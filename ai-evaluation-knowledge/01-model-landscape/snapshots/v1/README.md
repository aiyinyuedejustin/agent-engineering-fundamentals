# 模型报告证据快照 v1

研究日期：2026-11-06。此快照稳定，不再原地修改。

## 内容与数量语义

- `model-report-registry.md`：可读登记册。
- `data/model-report-registry.json`：94 条来源、索引或模型报告/版本记录，其中 19 条 D1、75 条 D0。不是 94 个模型，也不是 94 个独立 benchmark。D1 仅保证 `read_scope` 所写章节已核验。
- `data/model-benchmark-evidence.json`：42 个原文报告证据元组，全部 D1，未独立运行或复现。它们不是新增 42 个 benchmark，而是不同模型、配置、指标的观测。

D0 为发现未核验；D1 为官方报告/论文/文档核验；D2 为真实任务、配置和关键代码阅读；D3 为源码执行链追踪；D4 为实际运行或复现实验。此快照没有 D2–D4 声明。

## 来源与使用

记录里的 `source_id` 关联来源登记册的 `id`。`date` 可以是年月、日期或空值；`date_kind` 说明它是更新日期还是报道日期。不应补造精确时间戳。`observed_at` 只是本次阅读日期。

所有说明、结构化记录与比较限制为研究者整理，不包含原始报告镜像、完整文章或逐字摘抄。分数为已核验原文中的事实记录，不是本项目测试成绩。未写明的配置仍未知，不能默认相同。跨报告比较应重新核对任务子集、harness、推理预算、采样次数、版本、工具和 grader。

## 已知限制

- D0 的直接报告 URL 有时仍是官方索引入口，不应当作原文已经读过。
- 发布页、PDF 封面、arXiv 初稿/修订日期可能不同。Kimi K2、Gemini 3 Pro、GPT-5 的差异已记录；DeepSeek-V4 的返回日期与 arXiv 标识符月份存在未解决异常。
- 闭源报告部分表格是图片，未提取的图表不录入数值。
- Google 的 OSWorld 2.0 记录为离线子集 partial score，不能与 strict score 或在线/离线合计比较。
- Claude 的部分系统评测允许安全 fallback，所以该分数不能理解为单一权重裸模型的能力。
- 不提供统一模型总榜，不从厂商测试推出生产成功率。
